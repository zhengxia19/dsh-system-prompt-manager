# T01 技术可行性核查记录（完成：源码级）

日期：2026-10-20；目标版本：官方标签 dsh-v0.2.1-rc.2。
状态：T01 源码级可行性核查完成；真实桌面请求验收留给 T10。

## 结论

**纯插件方案具备实现路径，无需预先修改 DSH 核心。** 必须区分 Agent Loop 内部空 system/message 占位与 Provider 实际 wire 请求。

## 已验证的源码事实

1. packages/core/system-prompt/src/index.ts：PromptSection.complete 使该段成为唯一系统提示词；renderPrompt 忽略空段，interpolate:false 保留原文。多个 complete 段冲突会报错。
2. packages/core/agent-loop/src/agent.ts：每一步 assemble 后，系统提示词被投影成 durable system/message，最终请求由 session.deriveMessages() 构造。
3. packages/core/agent-loop/src/runtime-context.ts：第一轮即使系统文本为空，也会记录空 system/message 占位。因此只检查内部历史不足以认定无系统消息。
4. packages/llm/llm-pi-ai/src/context.ts：splitSystemPrompt() 忽略空字符串，返回 systemPrompt:undefined；piContext() 只在有非空系统文本时增加 systemPrompt 字段；appendSharedHistory 也跳过空系统文本。这为 Strata/OpenAI 兼容适配器提供了不发送 system 的路径（具体 provider 的适配器仍需验证）。
5. packages/llm/llm-deepseek/src/serialize.ts：系统文本为空时省略最终 system 字段；但 inHistory 空系统更新有潜在 UNSUPPORTED_CONTENT 边界，必须在历史会话切换用例中测试。
6. packages/core/agent/src/index.ts：AgentRegistry.list()、串行 agent/created 和 agent/disposed 公开事件可用；每个 agent.ctx 可注册 scoped 提示词段。
7. 客户端官方 conversation.input.left Slot 可通过 ctx.slots.inject 注册；但必须在 Windows Desktop 最终验证。

## 拟采用的纯插件方案

- 原生：不注册 complete 段。
- 自定义：Agent 作用域注册 complete:true + interpolate:false，精确模板文本。
- 无系统提示词：Agent 作用域注册 complete:true + text:''；必须实测最终 wire 上无 system 字段或角色消息，内部占位不是成功证据。
- 子 Agent 创建时继承父 Agent 当前执行快照；运行中模式变化推迟到 idle 后。
