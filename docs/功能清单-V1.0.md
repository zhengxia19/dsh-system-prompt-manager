# 功能清单 V1.0

状态：需求确认；均未实施。优先级 P0 必须验收，P1 本版要求实现，P2 不在本版实现。

| ID | 优先级 | 功能 | 验收要点 |
|---|---|---|---|
| F01 | P0 | 原生模式 | 请求与未启用插件相同 |
| F02 | P0 | 自定义完整替换 | 最终系统文本与选定模板逐字一致 |
| F03 | P0 | 无系统提示词 | 请求无 system 消息，不是空字符串 |
| F04 | P0 | 输入框常驻模式选择 | 发送前可选，切换反馈明确 |
| F05 | P0 | 多模板 CRUD 与复制 | 新增、编辑、重命名、删除、复制 |
| F06 | P0 | 会话状态独立与持久化 | 多会话隔离；重启恢复 |
| F07 | P0 | 历史会话即时切换 | 下一轮生效；显示历史影响提示 |
| F08 | P0 | 任务快照 | 执行中模板和模式不可漂移 |
| F09 | P0 | 子 Agent 继承 | 继承主任务执行快照，覆盖多级 |
| F10 | P0 | `/goal` 兼容 | 不破坏任务执行状态机 |
| F11 | P0 | 冲突与错误保护 | 未满足模式语义时不得静默发送 |
| F12 | P0 | Windows 桌面端兼容 | 目标版本实际测试通过 |
| F13 | P1 | 新会话默认模式设置 | 初始原生，可修改 |
| F14 | P1 | 提示词状态显示 | 当前模式/模板明确 |
| F15 | P1 | UTF-8/JSON 模板导入导出 | 无乱码、无隐式文本转换 |
| F16 | P1 | 诊断工具 | 可核对组装结果及实际请求结构，合理脱敏 |
| F17 | P2 | 历史模板版本管理 | 不在 V1.0 |
| F18 | P2 | AI 优化、云同步、模板市场 | 不在 V1.0 |

非功能限制：不改变模型参数、CV、工具 Schema、权限和普通运行时数据；不得修改 DSH 核心；不得增加固定系统提示词前后缀。
