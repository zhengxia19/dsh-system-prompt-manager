# 验收标准 V1.0

## 测试矩阵

| 测试编号 | 场景 | 必须满足的断言 |
|---|---|---|
| A01 | 禁用插件 / 原生模式 | 请求消息结构与原生基线等价；工具调用无回归 |
| A02 | 自定义模式 | 最终 system 文本逐字等于模板，无额外原生段/强制规则 |
| A03 | 无提示词模式 | 实际发送的消息数组不存在 `role=system` 项 |
| A04 | 模式切换 | 仅下一轮生效；进行中请求不变化 |
| A05 | 有历史会话切换 | 历史保留，UI 有影响提示；无错误复用旧 system |
| A06 | 多会话并发 | A/B 不同模式与模板互不串扰 |
| A07 | 重启恢复 | 会话与模板状态准确恢复 |
| A08 | 模板编辑/删除 | 新请求使用正确版本；被删除引用显式阻止发送 |
| A09 | 子 Agent | 一、二级子 Agent 继承创建时的精确快照 |
| A10 | `/goal` | Goal 执行和任务状态未被破坏；子 Agent 正确继承 |
| A11 | 与其他提示词插件冲突 | 检测完整替换冲突并提示，不能静默继续 |
| A12 | 故障注入 | 存储失败、模板错误、接口缺失等不静默降级 |
| A13 | 中文导入导出 | UTF-8 正确，文件名和内容不乱码 |
| A14 | 桌面版验证 | Windows DSH Desktop 目标版安装、切换、调用实测通过 |

## 证据要求

- 保存测试输入、预期、实际、通过/失败状态及版本号。
- A01-A03 必须包含经脱敏的真实 Provider 请求结构与组装结果对照，而非只看回答文本。
- A09-A10 需要父子 Agent 的模式/模板版本追踪，但日志不得默认泄露完整提示词。
- 外部服务端若自动注入系统模板，区分客户端请求事实与服务端行为，不误判插件成功或失败。

## 发布门槛

所有 P0 必须通过；P1 必须按需求交付；缺失实际 Windows 测试不得声称全面兼容。技术验证失败时记录阻碍，不降低验收定义。
