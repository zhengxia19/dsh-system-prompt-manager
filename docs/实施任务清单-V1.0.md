## 阶段门槛

T01 为硬门槛：若公开插件接口不能实现 F03，必须提交技术缺口与备选接口方案，停止依赖 F03 的后续实现；未经另行授权不能改 DSH 核心，也不能把空字符串算作成功。

## 工作纪律

- 每一任务：更新状态、记录修改文件和证据、说明阻碍及遗留风险。
- 不做与任务无关的大规模重构。
- 编译通过≠端到端通过；所有验收不得凭推测填写。
- 提交与发布仅在有实际结果时声明完成。
